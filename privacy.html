개인정보처리방침

적용일: 2026년 10월 25일

이 안내는 개인용 LifeVault Drive Sync의 Google Drive 연동과 이 안내 웹사이트에 적용합니다.

접근하는 데이터와 목적

올바른 계정인지 확인하기 위해 연결한 계정의 이메일 주소에 접근합니다. 보관함 전송과 내용 검증을 위해 지정한 Google Drive 폴더의 파일 이름, 폴더 구조, 수정 시각, 크기와 파일 내용에 접근하고, Mac의 문서와 첨부파일을 해당 폴더에 업로드·갱신합니다.

저장과 보호

원본 문서와 동기화 상태는 운영자가 관리하는 Mac에, 전송한 파일은 연결한 소유자의 Google Drive 계정에 저장합니다. OAuth 인증 정보는 해당 Mac의 접근이 제한된 설정 파일에 보관합니다. Google Drive와의 통신에는 HTTPS를 사용합니다. 기존 로컬 보관함과 백업의 보관 기간은 소유자가 정합니다.

사용과 공유의 범위

Google API에서 얻은 데이터는 소유자가 요청한 계정 확인·파일 동기화·전송 검증을 위해서만 사용합니다. 광고, 판매, 신용 평가 또는 범용 AI 모델 학습에 사용하지 않습니다. 지정된 Google Drive 전송과 운영자의 장치 외에 별도의 데이터 수집 서버를 운영하지 않습니다.

LifeVault Drive Sync의 Google API 정보 사용 및 전송은 Google API 서비스 사용자 데이터 정책과 제한적 사용(Limited Use) 요구사항을 따릅니다.

연결 해제와 삭제

Google 계정의 연결된 앱 설정에서 권한을 철회할 수 있습니다. 앱 실행을 중지하면 새 전송을 멈출 수 있습니다. 권한 철회만으로 이미 보관한 문서가 자동 삭제되지는 않으며, 소유자가 자신의 Mac과 Google Drive에서 파일을 관리하고 삭제합니다.

웹사이트 접속

이 안내 페이지에는 광고, 분석 스크립트나 자체 추적 쿠키를 넣지 않습니다. 페이지 호스팅 사업자인 GitHub는 보안 목적으로 방문자의 IP 주소를 기록할 수 있습니다. 자세한 사항은 GitHub 개인정보처리방침을 참고하세요.

문의와 변경

문의는 운영자의 GitHub 문의 페이지로 받을 수 있습니다. 공개 문의에는 보관함 내용이나 인증 정보를 첨부하지 마세요. 데이터 접근 목적이나 사용 범위가 바뀌면 이 안내를 갱신하고 필요한 동의를 다시 받습니다.
